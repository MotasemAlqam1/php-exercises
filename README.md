## Technologies Used

- PHP
- XAMPP
- Visual Studio Code
- Git and GitHub

## How to Run

1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone this repository:

   ```bash
   git clone https://github.com/MotasemAlqam1/php-exercises.git
   ```

3. Move the project folder into your XAMPP `htdocs` directory.
4. Start Apache from the XAMPP Control Panel.
5. Open the project in your browser:

   ```text
   http://localhost/php-exercises/
   ```
